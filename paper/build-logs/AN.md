### Interface choices other streams should know

- H1 rows: the input id of a DetectorVerdictRow is `inputId` if present, else `callId`; it must
  equal a FrameSpec `eligibleInputs` entry. A violated row with `at = null` is a first-element-only
  (receipt-level) row and is refused (exit 2, "per-element rows required"); when `at` indexes an
  element, `elementIndex` must equal that index. The origin unit is
  `FrameSpec.attribution[input][at]`, else the row's `originUnit`; a conflict is an error. Origin
  units that are not FrameSpec entity ids are collection-level (census and D12 only). Properties
  must be in `FrameSpec.families` (FP-capable) or `entailedProps` (sanity count).
- H2 matrix (HOLD): one row per (patch, test set): `{drift, patchId, correct, source, testSet in
  {fiks, agent, empty}, testId, variant in {final, first}, fOnBase, inlineRecording, accepted}`.
  The pool manifest carries `requestChanging` and `fiksTestEmitted` per drift; `fiksTestEmitted =
  false` selects T = empty.
- Grades join attempts by `GradeRecord.patchId` = the RunKey string, or = `headSha`.
  `AttemptRecord` may carry `infraError: true` and `contractUpdateProposed: true`; an exposed PR
  with `ciFinal = none`, or with a failed pre-PR IV, is rejected as inconsistent.
- `cp2_lock.py` writes `paper/results/raw/cp2/*` and the lock (with `frameSpec`, input, output
  and script hashes); it refuses if the lock exists. Every `e*_*.py` and `descriptive.py` exits 3
  without a valid lock (`--lock` overrides the path; tests use `$TMPDIR` only).
- `power.py mde` needs `eval_stats.py` at the path PLAN names (override:
  `PAPER_FORGE_EVAL_STATS`); without it, `mde` and `all --check` exit 2 / report errors.

### Open finding: simulate_null (ii) H3a at alpha 0.05 is conservative

`simulate_null.py --check --datasets 2000` (seed 20261021, fixed before the first run) passes
every row except (ii) H3a at alpha = 0.05: rejection 0.0335, below the two-sided band
alpha ± 3 MC SE = [0.0354, 0.0646]. The deviation is on the conservative side. Under the H3a null
DGP (green-incorrect rate per drift ~ Beta(1.5, 8.5), 3 models x 4 attempts, both arms equal),
about 30% of the per-drift differences are exactly 0 and the rest lie on a 1/12 lattice, so the
sign-flip distribution has atoms and the test cannot reach alpha. Three further runs of 20,000
datasets each (seeds 1, 2, 3) give 0.0410, 0.0401 and 0.0438 at alpha 0.05 (0.0093, 0.0091,
0.0105 at 0.0125). So the true size is about 0.04, inside the band, and the 2,000-dataset run
fell about 1.7 MC SE below it. The H4a row (Beta(2, 8)) passes at 0.0465.

The seed and the DGPs were not changed after this result. PLAN §9.1 (ii) asks for a two-sided
band, which treats a conservative test as a failure. The planner needs to decide one of: keep the
two-sided band and accept a reported conservative size, gate (ii) one-sided (<= alpha + 3 MC SE)
as (iii) and (iv) already are, or raise the dataset count for (ii). Until then this acceptance
item is not met.
