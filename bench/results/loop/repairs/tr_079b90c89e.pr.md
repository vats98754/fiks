## Fix
Fixed: `get_product` now returns the price again for the new vendor version, and typecheck, lint and all 14 tests pass, including the repro test and the v1 fixtures. The cause is that vendor version 2026-10-01 renamed the product field `price` to `unit_amount` without updating its spec. The value didn't change and is still in US dollars: p-1001 comes back as 1199 under both versions. `src/tools/get_product.ts` only read `p.price`, so on the new version `p.price ?? null` quietly became `null`. The fix adds an optional `unit_amount` to the `VendorProduct` type and maps `price: p.price ?? p.unit_amount ?? null`. The old version (2026-01-01) still sends `price`, so its output is unchanged. No new HTTP requests are sent, so the recording doesn't need to be re-recorded.
